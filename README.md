# Sales Trend Visualization 

## Project Overview

This project analyzes e-commerce sales data using Python and visualizes important business insights through graphs and dashboards.  
It also predicts future sales trends using Machine Learning.

The project is built using:
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

---

## Features

- Data Cleaning and Preprocessing
- Monthly Sales Trend Analysis
- Category Wise Sales Visualization
- Region Wise Profit Analysis
- Top 10 Selling Products Analysis
- Sales Distribution Visualization
- Correlation Heatmap
- Sales Prediction using Linear Regression
- Interactive Streamlit Dashboard

---

## Technologies Used

- Python
- Pandas
- Matplotlib
